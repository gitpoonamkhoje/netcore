Option 2 (Single Vault, Manual Secret Lookup)

Store:

Dev--AppResources--SqlConnectionString
Cert--AppResources--SqlConnectionString
Prod--AppResources--SqlConnectionString

Then add:

EnvironmentName=Dev

in Function App settings.

And read manually:

var env = configuration["EnvironmentName"];

var secretName = $"{env}--AppResources--SqlConnectionString";

var secret = await secretClient.GetSecretAsync(secretName);

How Option 2 works
Key Vault secrets (one vault):

Dev--AppResources--SqlConnectionString
Cert--AppResources--SqlConnectionString
Prod--AppResources--SqlConnectionString
same pattern for other keys

Function App settings (per app):
KeyVaultUri=https://your-vault.vault.azure.net/
AppEnvironmentCode=Dev (or Cert / Prod)
ASPNETCORE_ENVIRONMENT=Development (or Certification / Production)
Important: use AppEnvironmentCode, not EnvironmentName, because EnvironmentName is already used by ASP.NET/Functions for hosting (Development, Certification, Production).
